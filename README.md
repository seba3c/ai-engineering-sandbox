# ai-engineering-sandbox

This my own sandbox for AI engineering tests and proof of concepts, while following the courses:

- [AI Engineer Core Track: LLM Engineering, RAG, QLoRA, Agents](https://www.udemy.com/course-dashboard-redirect/?course_id=6100015) by Ed Donner

To properly use the python labs you need to create an .env file and put your LLM provider API keys:

```
OPENAI_API_KEY=<your open ai api key>
GOOGLE_API_KEY=<your google ai api key>
ANTHROPIC_API_KEY=<your anthropic ai api key>
...
```
